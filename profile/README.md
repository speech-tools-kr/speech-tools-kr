# SpeechTools

한국어 음성 AI 회사입니다. 음성인식(STT)·대화 관리(LLM)·음성합성(TTS)을 묶어
전화·방송 현장에서 바로 쓰는 시스템을 만듭니다.

## 하는 일

- **AICC(인공지능 고객센터)** — 전화 여론조사, 엘리베이터 고객센터 등 음성 대화 자동화
- **실시간 자막** — 한국어 방송 자막 실시간 생성(온프렘 STT)
- **음성 모델 연구** — 한국어 STT 파인튜닝, 음성 보정, End-to-End 음성 모델 평가

## 저장소

| 저장소 | 내용 |
|---|---|
| `aicc_poll` | 전화 여론조사 AICC 통화 흐름(STT → LLM → TTS) |
| `ST_AICC_elevator_backend` | 엘리베이터 AICC 백엔드 |
| `website` | 회사 홈페이지 소스 |
